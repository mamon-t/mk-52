## Известные блокеры

- Для GUI на Linux нужны dev-пакеты X11/Wayland/fontconfig (перечислены в CI).
- История сжата в один корневой коммит; `.git` занимает около 3 МБ. Внешняя
  резервная копия прежней истории создана на время перезаписи.
- Полная микрокодовая точность К145ИК130x не заявляется: модель тактуется
  по фазам M1..M4, но инструкция ГП исполняется целиком на M1 (см. `docs/architecture.md`).
